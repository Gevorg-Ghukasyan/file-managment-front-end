# DataBox

DataBox is a modern React + Vite file management dashboard for organizing your uploads, groups, and files with a clean interface.

## Features

- Route-based file views: My Files, Groups, Upload
- Responsive layout with sidebar, header and footer
- Search and notifications UI
- Project branding refactored from E-Journal to DataBox

## Local development

1. `npm install`
2. `npm run dev`

## Production

- `npm run build`
- `npm run preview`

## Notes

- App routes are defined in `src/App.jsx`
- UI is composed in `src/components/`
- Page views in `src/pages/`
- Service layer in `src/services/`
